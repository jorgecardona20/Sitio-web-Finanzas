## Recordatorios (app para cualquier celular)

En la carpeta [`recordatorios/`](recordatorios/) hay una app de recordatorios estilo Samsung Reminder,
hecha como PWA (Progressive Web App): se instala desde el navegador en Android, iPhone y cualquier celular,
sin tienda de apps.

- Listas inteligentes: Hoy, Programados, Todos, Destacados y Completados
- Listas propias con colores
- Fecha, hora y repetición (diaria, laborables, semanal, mensual, anual)
- Notificaciones con acciones "Completar" y "Posponer 10 min"
- Exportar a calendario (.ics) con alarma, para avisos garantizados con la app cerrada
- Búsqueda, modo oscuro, funciona sin conexión
- Copia de seguridad: exportar e importar en JSON

Para usarla, publica el sitio con HTTPS (por ejemplo GitHub Pages) y abre `/recordatorios/` en el celular.
Los datos se guardan solo en el dispositivo.
